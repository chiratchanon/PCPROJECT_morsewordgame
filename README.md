
# Physical Computing Project 2026 - IT KMITL


## เกี่ยวกับโปรเจกต์
**ที่มาและเป้าหมาย**

* Morse Code คือ วิธีการเข้ารหัสและส่งข้อความระยะไกล โดยเปลี่ยนตัวอักษร ตัวเลข หรือเครื่องหมายวรรคตอน ให้กลายเป็นชุดสัญญาณที่มีสั้น (.) และยาว (-) ซึ่งสามารถส่งผ่านเสียงเคาะ แสงไฟ หรือการกะพริบตาได้

* เป้าหมายของโปรเจกต์คือเพื่อการศึกษาเกี่ยวกับรหัสมอร์ส ทำให้การเรียนรู้รหัสมอร์ส มีความน่าสนใจมากขึ้น

## ความสำคัญและผู้ได้ประโยชน์
**ความสำคัญ**
- เป็นตัวอย่างการเชื่อมอุปกรณ์เข้ากับเว็บ
- ทำให้การเรียนรู้รหัสมอร์สสนุกขึ้นด้วยเกมแข่งคะแนน
- แสดงการประมวลผลเสียงแบบง่ายบนอุปกรณ์ราคาถูก
- เป็นต้นแบบที่ต่อยอดได้ โดยโครงสร้างอุปกรณ์ + MQTT + Web นำไปใช้กับงานอื่นได้

**ผู้ได้ประโยชน์**
 
| กลุ่ม | ประโยชน์ที่ได้รับ |
|---|---|
| นักเรียน นักศึกษา | ได้ตัวอย่างโปรเจกต์พร้อม Source Code ให้ศึกษาและดัดแปลง |
| ผู้ที่สนใจรหัสมอร์ส | มีเครื่องมือฝึกสะกดรหัสมอร์ส |
| ครูและผู้จัดกิจกรรม | ใช้เป็นกิจกรรมในห้องเรียนหรือค่ายได้ เพราะรองรับหลายบอร์ดและมีตารางคะแนน |
